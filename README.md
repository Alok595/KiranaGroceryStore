# 🛒 Kirana Grocery Delivery App

A full-stack grocery delivery platform designed to digitize local kirana stores with three user roles: **Customer**, **Delivery Partner**, and **Admin**. The app provides real-time order tracking, in-app chat, direct calling with assigned delivery partners, and secure payments using **Stripe**. Built with **Socket.IO** for live updates, it ensures fast, reliable, and seamless doorstep delivery.

---

## 🚀 Features

* 👤 Multi-role authentication (User, Delivery Boy, Admin)
* 📍 Live order tracking
* 💬 In-app chat with delivery partner
* 📞 Call assigned delivery partner
* 💳 Stripe payment gateway integration
* ⚡ Real-time updates using Socket.IO
* 📦 Order management dashboard for admin

---

## 🛠️ Tech Stack

* Frontend:  Next.js 
* Backend: Node.js, Express
* Database: MongoDB / PostgreSQL
* Real-time: Socket.IO
* Payments: Stripe
